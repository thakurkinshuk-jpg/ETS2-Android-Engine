
# ETS2 Android Engine

An experimental native Android engine project aiming to load and render Euro Truck Simulator 2 game assets.

## Goal
Build an Android application that can progressively load ETS2 assets and eventually support a playable driving experience.

## Target device
Samsung Galaxy A35 5G.

## Planned features
- ETS2 SCS HashFS archive reader
- Asset and model loading
- Android 3D rendering
- Vehicle physics and driving
- Touch controls for steering, accelerator, brake, gears and camera

## Important
This project does not include ETS2 copyrighted game files. Users must provide their own legally obtained game files.
